# BCIT BBY Campus Map
 
## Overview
 
An all-in-one interactive map for the BCIT Burnaby campus. Students can search for rooms and buildings, view floor plans, filter washrooms certain things and areas, and save personal bookmarks, so they spend less time figuring out where they are. Built mobile first, with a desktop layout as well.
 
---
 
## Features
 
* Sign up, log in, and log out with Firebase Authentication
* Search for rooms and buildings with autocomplete suggestions and a Recents list
* Tap a building to open a details panel with a room search bar, or tap and hold the map to drop a pin
* Switch between floor plans within a building
* Filter the map to show washrooms and dining areas
* Bookmark locations, then rename or remove them from the Bookmarks menu
---
 
## Technologies Used
 
* Frontend: HTML5, CSS, Bootstrap, JavaScript
* Map: [MapLibre GL JS](https://maplibre.org/) for rendering, [MapTiler](https://www.maptiler.com/) for map tiles and styling
* Build and server: Node.js, Vite, and Express through vite-express
* Backend: Firebase Authentication and Cloud Firestore
* Data prep: [geojson.io](https://geojson.io/) for drawing building outlines and floor plans, aligned to real-world coordinates
* UI: SweetAlert2 for pop-up alerts and confirmations

## Usage
 
To run the application locally:
 
1. Clone the repository.
2. Install dependencies by running `npm install` in the project root directory.
3. Create a `.env` file in the project root with your Firebase config values. Every variable must be prefixed with `VITE_` to be exposed to the client. Do not push this file to GitHub.
4. Start the development server by running `npm run dev`.
5. Open your browser and visit the local address shown in your terminal (usually `http://localhost:5173` or similar).
Once the application is running:
 
1. Skip registration or log in to unlock bookmarks and recent searches.
2. Search for a room or building, or tap a building on the map.
3. Switch floors, bookmark a location, or apply the washroom and dining filters.

## Project Structure

```
├── app/html          <-- HTML files & must be individually exposed in vite.config.js
├── doc/              <-- JS files and Firestore schema documentation
├── node_modules/     <-- Installed npm packages. Generated by npm install, not committed to git

├── tooling/          <-- Helper scripts, not part of the running app

├── package-lock.json <-- Locks exact versions of every installed package so installs match
├── package.json      <-- Project name, scripts such as npm run dev, and the dependency list
├── README.md         <-- Project overview, setup steps, and team information
└── vite.config.js    <-- Vite build and dev server settings
```
